# LaunchCase 项目 Cue 展示脚本

请把当前 LaunchCase 项目制作成一个可交互、可现场演示的产品展示，不要做成传统 PPT。整体视觉沿用现有项目：深海蓝、青绿色发光线条、少量暖橙色点缀，保持克制、清晰、具有空间感。所有页面使用中文，关键英文作为小号辅助标签。

## 演示结构

### 1. 首页：越过山海 抵达无限

- 画面分成连续融合的海洋与沙漠，不要出现硬切分界线。
- 左侧是蓝紫冷色海洋，包含自然跃起的海豚和飞溅浪花。
- 右侧是米色、橙黄色沙漠，包含连续起伏的沙丘和持续行走的骆驼。
- 底部让轮船沿海岸线移动并自然过渡为汽车，作为进入三个工作台的导航。
- 标语显示为“越过山海 抵达无限”，无标点，使用颗粒流动感字体。
- 首页已完成，演示时只展示，不重做其设计。

### 2. TradeCase：跨境询盘工作台

- 以可旋转、可点击的地球作为主视觉，工作台、询盘案件、决策收件箱、跟进计划、来源与知识、工作区设置分别对应洲和洋。
- 点击任一入口后，地球缩小并停靠左下角，左上角显示当前工作区标题，右侧进入原有工作流界面。
- 使用深蓝黑背景、青绿色高亮和清晰的证据链节点，体现可追溯决策。
- 演示“询盘案件 → 审核收件箱 → 跟进计划”的完整路径，强调所有判断由人工确认。

### 3. CreativeEngine：视觉生产工作台

- 保留机器人 ROBO 元素，机器人固定在页面右侧，在从项目总览、需求与素材、视觉生产计划、批次监控到审核交付的整个滚动过程中始终可见。
- 机器人有轻微漂浮、眨眼和核心呼吸光效，不遮挡主要按钮和表单。
- 演示从上传来源素材、明确创意方向、生成生产计划到审核交付的流程。
- 使用深绿色、米白色和荧光绿色，保持 OKATHON 风格的产线感。

### 4. LaunchCase：跨境电商工作台

- 以大型发光集装箱为中心，周围散落家电、文具、零部件、五金工具、包装等商品入口。
- 商品入口通过发光航线和悬浮动作连接到集装箱，点击商品进入原有具体步骤。
- 产品项目、审核收件箱、来源与知识、概念图片、能力与设置及项目详情统一使用深蓝主题。
- 顶部提供“← 返回首页”入口，可返回 4320 端口的项目首页。
- 去除 TradeCase/tags 中的内部版本字符串和身份凭证展示，不生成新的身份凭证。

## 现场演示交互

1. 先从首页点击轮船或汽车，进入三个工作台选择。
2. 进入 TradeCase，旋转地球并点击“询盘案件”，展示地球缩小、工作区标题出现和右侧工作流加载。
3. 返回首页后进入 CreativeEngine，连续滚动四个生产站点，展示机器人始终在右侧陪伴。
4. 返回首页后进入 LaunchCase，点击集装箱周围的家电或五金工具，展示对应流程详情。
5. 每次切换都使用平滑过渡、发光路径和轻微景深，避免卡通化或突然跳转。

## 文案与边界

- 所有概念图片和模拟数据明确标记为“概念”或“离线样例”。
- 不展示本地令牌、身份凭证、内部版本字符串或真实客户数据。
- 不宣称真实市场验证、合规认证、供应商报价或已发布商品。
- 最后一屏显示： “LaunchCase · 先核实，再决策。”

请生成一个可点击的长页面演示，支持桌面全屏和手机竖屏，提供返回首页、工作台导航、暂停动画和全屏按钮。不要生成传统幻灯片分页；把它做成连续的产品体验。
