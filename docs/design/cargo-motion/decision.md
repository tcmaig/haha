# Motion and visual alignment for the third workbench

Current direct human request: the third cross-border e-commerce workbench feels inconsistent with the effects and movements of the first two; make it more vivid and coordinate their visual language. The human has superseded T-012's cream/green entry palette. The existing container-centered navigation and all eight original step mappings remain the boundary. The shared ocean/desert homepage and the other two workbench sources are not edited.

Read-only local references: TradeCase globe.css/globe-navigation.tsx use navy space, lit orbit pins and continuous globe motion. CreativeEngine roboline.css/robot.tsx use dark backgrounds, luminous green accents, a floating robot and hover interactions. This implementation uses a complementary blue/cyan/violet cargo port, metallic 3D vector container, floating goods, traveling route lights, subtle particles and pointer parallax. Clicking gives a 380ms visual departure before calling the original step handler; reduced motion and manual pause skip that delay.

The entry shell alone is darkened; original detail forms remain in their existing theme. All graphics are local vector/canvas decoration, not real product evidence. No new dependencies, generated credentials, paid services or external data. Continuous effects pause when out of view, when the tab is hidden, on user pause, and under reduced-motion preference.

The baseline is the exact previous runtime screenshot, which the user identified as visually insufficient. It is retained for comparison, not asserted as human design-approved. The new visual result remains pending human review.
